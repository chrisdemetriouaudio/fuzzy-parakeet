AI Documentation

Welcome to the AI working documentation for ChrisDemetriou.com Version 2.

This folder contains the strategic, creative and engineering documentation that defines the project.

It exists to ensure every future AI assistant, developer or contributor understands the vision before making changes.

These documents are the authoritative source for design decisions, positioning, UX philosophy and implementation guidance.

Application code should follow these documents, not redefine them.

Repository Philosophy

This repository does not exist simply to build a personal website.

It exists to build a premium digital product that represents Chris Demetriou’s professional brand.

The objective is to create what should become the benchmark personal website for Enterprise Technology Operations professionals.

Every design decision, animation, interaction, paragraph and component should reinforce that objective.

⸻

Project Goals

The website should:

* communicate enterprise technology expertise immediately
* resonate with recruiters, hiring managers, CIOs and CTOs
* demonstrate systems thinking rather than list responsibilities
* feel like a premium SaaS product
* remain accessible, performant and maintainable
* evolve over many years without losing consistency

The website is intentionally not:

* an online CV
* a LinkedIn profile
* a chronological career history
* a generic portfolio

⸻

Primary Positioning

Chris is positioned as an:

Enterprise Technology Operations Manager

He should never be primarily perceived as:

* Project Manager
* Programme Manager
* Technical Program Manager
* Scrum Master
* PMO
* IT Support
* Help Desk
* Service Desk
* Customer Success

The website must consistently communicate that his value comes from understanding enterprise technology as an interconnected system.

⸻

Core Brand Principles

Everything should reinforce these ideas.

* Enterprise technology succeeds because people understand dependencies.
* Technology rarely fails because of the technology alone.
* The right conversations prevent expensive surprises.
* Complexity should become understandable.
* Enterprise systems thinking is the differentiator.
* Show expertise through experience rather than buzzwords.
* Demonstrate value visually wherever possible.

⸻

Design Principles

The experience should feel:

* premium
* elegant
* calm
* confident
* intentional
* modern
* understated

Visual inspiration includes:

* Apple
* Linear
* Vercel
* GitHub
* Raycast
* Notion

Avoid visual clutter.

Avoid unnecessary decoration.

Whitespace is a feature.

⸻

User Experience Principles

Visitors should never feel overwhelmed.

Design for scanning first.

Reading second.

Use:

* generous whitespace
* large typography
* progressive disclosure
* diagrams
* interactive explanations
* subtle animation
* visual hierarchy

Avoid walls of text.

Every section should communicate one clear idea.

⸻

Accessibility Principles

Accessibility is not an afterthought.

It is a design principle.

The website should provide:

* Dark Mode by default
* Light Mode support
* Focus Mode
* Read Aloud
* Reading preferences
* WCAG 2.2 AA compliance
* keyboard accessibility
* reduced motion support
* semantic HTML

These features exist to improve the experience for everyone.

⸻

Creative Media

Creative Media represents a second professional career.

It is not a hobby.

However:

Enterprise Technology remains the primary commercial objective.

Technology should always receive greater visual emphasis.

Creative Media should reinforce the overall brand rather than compete with it.

⸻

AI Workflow

Before making changes:

1. Read the documentation.
2. Understand the reasoning.
3. Challenge assumptions where appropriate.
4. Preserve the project’s philosophy.
5. Implement incrementally.
6. Document significant decisions.
7. Commit frequently.

Never optimise one area at the expense of the overall vision.
