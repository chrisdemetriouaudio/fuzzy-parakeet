Design Inspiration

Purpose

This document captures the design influences, interaction patterns and product qualities that should inspire ChrisDemetriou.com Version 2.

The objective is inspiration, not imitation.

Borrow principles.

Never copy interfaces.

⸻

Overall Experience

The website should feel like a premium software product.

Visitors should think:

“This feels like something built by a world-class product team.”

Not:

“This is a nice portfolio.”

⸻

Apple

Reference for:

* Typography
* Simplicity
* Whitespace
* Confidence
* Editorial presentation
* Product storytelling

Avoid copying Apple’s layouts directly.

Adopt the discipline behind them.

⸻

Linear

Reference for:

* Motion
* Micro-interactions
* Product polish
* Modern SaaS aesthetic
* Elegant dark mode

Linear demonstrates how subtle motion can improve usability.

⸻

Vercel

Reference for:

* Technical credibility
* Layout discipline
* Documentation quality
* Performance-first thinking

Use Vercel as a benchmark for engineering craftsmanship.

⸻

GitHub

Reference for:

* Developer trust
* Technical authenticity
* Clear information hierarchy
* Practical UX

The website should feel equally credible to engineers and executives.

⸻

Raycast

Reference for:

* Dark interface quality
* Attention to detail
* Precision
* Minimalism

Use Raycast as inspiration for premium utility features such as Focus Mode and Reading Preferences.

⸻

Notion

Reference for:

* Readability
* Calm layout
* Content hierarchy
* Long-form reading

Useful when designing articles and case studies.

⸻

Stripe

Reference for:

* Product storytelling
* Explaining complex concepts visually
* High-quality illustrations

Use the storytelling approach, not the visual style.

⸻

Figma

Reference for:

* Design systems
* Component thinking
* Structured interfaces

Every UI decision should feel intentional.

⸻

IBM Design Language

Reference for:

* Enterprise credibility
* Information architecture
* Professional restraint

Useful for enterprise-oriented layouts.

⸻

GOV.UK Design System

Reference for:

* Accessibility
* Plain language
* User-centred thinking

Not for aesthetics.

For clarity and inclusivity.

⸻

Editorial Inspiration

Draw inspiration from publications such as:

* Wired
* Monocle
* MIT Technology Review

Content should feel informative and considered.

⸻

Motion Inspiration

Motion should resemble:

* Linear
* Apple
* Raycast

Characteristics:

* subtle
* smooth
* restrained
* purposeful

Never use motion as decoration.

⸻

Interaction Inspiration

Prioritise interactions that:

Explain.

Guide.

Clarify.

Reduce cognitive effort.

Avoid interactions that exist only to entertain.

⸻

Photography Inspiration

Editorial.

Documentary.

Natural.

Professional.

Authentic.

Avoid heavily staged corporate imagery.

⸻

Accessibility Inspiration

Treat accessibility as a premium feature.

The best digital products make accessibility feel invisible because it is thoughtfully integrated.

⸻

What We Never Copy

Never recreate another company’s homepage.

Never imitate branding.

Never reproduce distinctive layouts.

Never sacrifice originality for familiarity.

⸻

Success Criteria

When reviewing the website ask:

Does this feel like a premium enterprise product?

Does it communicate calm confidence?

Does it simplify complexity?

Would a recruiter remember the experience?

Would a CTO trust the person behind it?

If the answer to these questions is yes, the inspiration has been applied successfully without becoming imitation.
