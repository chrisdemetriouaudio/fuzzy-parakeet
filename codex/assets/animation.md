Animation Principles

Purpose

Animation exists to improve understanding.

Never to impress.

Every movement should communicate meaning.

If an animation does not improve comprehension it should be removed.

⸻

Brand Personality

Animations should feel:

* Calm
* Intelligent
* Premium
* Deliberate
* Refined
* Confident

Avoid:

* Flashy effects
* Bounce animations
* Overly playful interactions
* Motion that distracts

⸻

Motion Philosophy

Motion should answer one of four questions:

What changed?

Where should I look?

How are these ideas connected?

What happened next?

If it answers none of these, it probably shouldn’t exist.

⸻

Signature Animation

Enterprise Information Flow

This is the defining interaction of the website.

Technical disciplines appear on the left.

Examples:

Engineering

Infrastructure

Networking

Security

Enterprise Applications

Third-party Vendors

Technical information flows towards Chris.

Examples:

API Dependency

VLAN Required

Firewall Rule

CAB Approval

Rollback Strategy

Identity Mapping

The information pauses.

Chris evaluates the context.

The information leaves transformed.

Outputs include:

Change approval required.

Network preparation needed.

Vendor coordination required.

Business impact confirmed.

Recovery plan agreed.

Different audiences receive different information.

The animation demonstrates judgement.

Not translation.

⸻

Portrait Reveal

The homepage should begin without a portrait.

As the visitor scrolls, Chris gradually appears.

The insight comes first.

The person comes second.

The transition should feel effortless.

⸻

Scroll Animations

Use subtle reveal animations.

Prefer:

Fade

Slide

Opacity

Small vertical movement

Avoid:

Large movement

Rotation

3D effects

Parallax overload

⸻

Hover States

Hover should communicate interactivity.

Examples:

Cards gently lift.

Buttons subtly brighten.

Diagrams highlight relationships.

Enterprise flows activate.

Nothing should bounce or wobble.

⸻

Diagram Animation

Enterprise diagrams should animate progressively.

Reveal relationships one at a time.

Allow visitors to understand complexity gradually.

Avoid displaying every connection simultaneously.

⸻

Reading Experience

Focus Mode should fade away non-essential interface elements.

Read Aloud should visually highlight the current sentence where practical.

Reading preference changes should transition smoothly without reloading the page.

⸻

Navigation

Navigation transitions should feel instantaneous.

Theme switching should be smooth.

Tab changes should preserve context.

Scrolling should never feel interrupted.

⸻

Loading States

Skeleton loading where appropriate.

Avoid spinners whenever possible.

Content should appear progressively.

⸻

Timing

General UI:

150 to 250ms

Section reveals:

300 to 500ms

Hero sequences:

600 to 900mss

Information Flow:

User controlled through scrolling rather than automatic playback.

⸻

Reduced Motion

Respect operating system preferences.

Provide an excellent experience without animation.

Never rely on animation alone to communicate important information.

⸻

Performance

Target:

60fps.

GPU-friendly animations.

Avoid layout shifts.

Prefer opacity and transforms.

Optimise for mobile.

⸻

Final Principle

Visitors should remember what the animation explained.

Not the animation itself.

Motion succeeds when it quietly improves understanding without drawing attention to its own existence.
