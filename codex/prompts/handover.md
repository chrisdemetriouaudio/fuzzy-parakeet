Project Handover Prompt

Purpose

Use this prompt whenever a new AI assistant joins the project or an existing assistant resumes work after a break.

Its purpose is to establish shared understanding before any new implementation begins.

⸻

Your Role

You are joining an established product team.

Do not assume this is a new project.

Your first responsibility is understanding the existing vision.

Only then should you begin making recommendations or writing code.

⸻

Step 1. Read the Documentation

Read these documents in order:

1. ../README.md
2. ../00_PROJECT_VISION.md
3. ../01_CREATIVE_BRIEF.md
4. ../02_IMPLEMENTATION_BRIEF.md
5. ../03_DESIGN_SYSTEM.md
6. ../04_CONTENT_STRATEGY.md
7. ../05_SEO_AI_ATS_STRATEGY.md
8. ../06_DECISION_LOG.md

Then review:

assets/

prompts/

Only continue once the documentation has been understood.

⸻

Step 2. Review the Repository

Analyse:

Project structure

Current implementation

Architecture

Components

Styling

Accessibility

Performance

Responsive behaviour

Git history

Identify:

Completed work

Work in progress

Technical debt

Potential risks

Outstanding opportunities

⸻

Step 3. Summarise Understanding

Provide a concise summary covering:

The project’s purpose.

The intended audience.

The primary positioning.

The design philosophy.

The engineering philosophy.

The current implementation status.

The next logical milestone.

Do not begin coding yet.

⸻

Step 4. Validate Alignment

Confirm that your understanding matches the documentation.

Highlight any inconsistencies.

If repository code contradicts the documentation:

Explain the conflict.

Recommend the preferred direction.

Do not silently choose one.

⸻

Step 5. Recommend the Next Milestone

Recommend only one milestone.

Explain:

Why it should be next.

Expected outcome.

Estimated scope.

Potential risks.

Dependencies.

Wait for approval before implementing.

⸻

Implementation Rules

When implementation begins:

Work incrementally.

Commit frequently.

Document decisions.

Preserve accessibility.

Protect performance.

Maintain consistency.

Never sacrifice the project’s vision for convenience.

⸻

If Unsure

Do not guess.

Explain the uncertainty.

Ask focused questions.

Reference the relevant documentation.

⸻

Deliverables

Return:

Project Summary

Current Status

Documentation Review

Architecture Review

Risks

Opportunities

Recommended Next Milestone

Questions (if any)

⸻

Final Principle

Every new AI assistant should leave the project in a better state than they found it.

Maintain consistency.

Respect the vision.

Improve thoughtfully.

The documentation is the source of truth.
