# 🧭 How this vault works

> [!info] At a glance
> **What:** the to-do list and history for chrisdemetriou.com and Labs (labs.chrisdemetriou.com).
> **Start here:** [[00 Dashboard]].
> **Updated:** 17 Oct 2026

## 🗺️ Where things are

- **[[00 Dashboard]]**: what needs doing now. Open this first.
- **[[Live status]]**: writes itself. Are the sites up, which build, open pull requests.
- **`10 Phases/`**: one page per chunk of work, from the first upload (27 Feb 2026) onwards.
- **[[Backlog & Parked]]**: ideas for later and things on hold.
- **[[Decision Log]]**: what we decided, and why.
- **[[Changelog]]**: what went live, and when.

## 🔣 What the symbols mean

Each symbol means one thing, on every page.

- 👉 **Your action**: something only you can do (a click in the app, a dashboard, a decision).
- 🛠️ **For Claude**: building work Claude does.
- ⏳ **Waiting**: stuck until something else happens.
- 💭 **Later**: an idea, not planned yet.
- 🅿️ **Parked**: deliberately on hold.
- 🔴 **Problem**: something broken that needs attention.
- ✅ **Done**: finished and checked.

## 📐 Writing rules (for everyone adding to this vault, Claude included)

1. **Same shape on every page.** Top: an "At a glance" box with what it is, status and date. Then **To do**. Then **Done**, folded away.
2. **Open work first.** Finished items never sit among open ones. They go into the folded ✅ Done box at the bottom.
3. **One task, one line.** Start with a verb in bold. Keep it under about 15 words. Put details in a folded box or on the phase page.
4. **Short sentences.** No paragraph longer than 3 lines. Plain words. Explain any technical term the first time.
5. **Dates as words.** Write "16 Oct 2026", never "2026-10-16", and never "today" or "yesterday".
6. **Symbols from the list above only**, with the same meaning every time.
7. **Bold the key words only.** No italics, no capitals for emphasis.
8. **Status is checked, not guessed.** Before ticking something, confirm it on the live system.
9. **After every release:** update the Dashboard, the phase page, the Changelog (one folded box, newest on top), the Decision Log (if a choice was made) and the Backlog.
10. **Nothing private.** This vault is public (see below).

## 🧩 Folded boxes

Grey boxes with a ▸ arrow are folded. Tap the title to open them. They hold finished work and background detail, so the page stays calm.

## 🎨 Easier reading

The vault turns on a reading style: bigger text, more space between lines, bigger checkboxes. It's in `.obsidian/snippets/pmo-readable.css`. To switch it off: Settings → Appearance → CSS snippets.

## 🔄 How it stays live

- **Your edits:** the Obsidian Git plugin saves them to GitHub about 10 minutes after you stop typing.
- **Other changes:** it pulls from GitHub every 5 minutes, and when Obsidian opens.
- **[[Live status]]:** a GitHub job rewrites it on every change, when pull requests open or close, and every 15 minutes.

## 🔒 This vault is public

It lives in the public fuzzy-parakeet repository. It is kept off chrisdemetriou.com, but anyone can read it on GitHub.

- **Never write** passwords, keys, tokens, private e-mail addresses or other people's personal details here.
- **Private notes** go in the Genesis PMO (a private repository) or stay off GitHub.
