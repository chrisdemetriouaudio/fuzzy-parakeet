FAQ

Straight answers.

What is a custom internal tool?

A custom internal tool is bespoke business software built for one organisation’s workflow, such as a booking engine, reminder pipeline or payment tracker, instead of a general product rented per user per month.

Who builds custom software in Manchester?

I’m Chris Demetriou, an independent software developer and consultant based in Manchester. I design, build, test and launch custom software, tools and web applications for organisations across the UK.

What does bespoke software development involve?

With me, it starts with understanding the problem in writing. I then design a solution and agree a fixed-price scope, build and test it, launch it, and hand over the code, accounts and plain-English notes.

How is a bespoke tool different from SaaS?

SaaS is rented per user, per month, and built for everyone. A bespoke tool is built once for your process and owned by you, so there are no seat licences. That is Zero Software Tax.

Do I own the software?

Yes. From handover, the code sits in your GitHub account and the tool runs in your Cloudflare account. If we stop working together, it keeps running.

What does it cost to run?

No licence fees. Infrastructure is billed to your own accounts at cost, typically from about £4 a month. Stripe’s standard card fees and per-message charges for WhatsApp alerts are pay-as-you-go.

How is the build priced?

Fixed price per agreed scope. You get a written scope and price before any work starts.

Do I need to be technical?

No. Describe the problem in your own words. Every step is explained in plain English.

Is our data safe?

Tools use encrypted connections and secure sign-in, collect only what they need, and store data in your own accounts. You know where every record lives before the build starts.

What if you’re not around?

Every tool ships with plain-English notes on how it works and how to run it, and the code and accounts are already yours, so nothing depends on one person.

Do I have to get on a call?

No. The workflow audit, the scope and the updates are all written, by email, so you keep a record of every decision.

Can it take card payments through Stripe?

Yes. The Payment Pipeline issues invoices, takes card payments through Stripe and verifies each payment before marking it paid.
